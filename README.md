# Ashwin S Portfolio

Modern responsive developer portfolio built with React, Vite, CSS, React Icons, and Framer Motion.

## Run Locally

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```

## Hosting

### Vercel

1. Push this project to GitHub.
2. Import the repository in Vercel.
3. Vercel will use:
   - Build command: `npm run build`
   - Output directory: `dist`

### Netlify

1. Push this project to GitHub.
2. Import the repository in Netlify.
3. Netlify will use:
   - Build command: `npm run build`
   - Publish directory: `dist`

## Sections

- Hero with typing animation and call-to-action links
- About with timeline and stats
- Categorized skills
- Featured projects
- Contact form and social links
- Responsive navbar and footer
